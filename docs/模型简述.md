# 数学模型简要说明

以十分钟为一个时段，联合决定计划购电、储能充放电和必要的紧急购电。统一约束包含能量平衡、储能容量上下限、充放电功率限制和充放电效率。

典型日采用线性规划，日末储能回到初始状态。年度问题利用历史场景描述预测误差，日前制定计划，日内结合已发布信息滚动调整；波动电价方案进一步改变购电成本输入。年度储能状态跨日连续，1 月用于初始化和预测校准，2 月至 12 月作为费用评价区间。

模型参数见 `src/model_config.py`，线性规划基础见 `src/optimization.py`，随机场景与策略分别见 `src/causal_scenarios.py`、`src/stochastic.py` 和 `src/dispatch.py`。五组结果分别归档在 `result` 目录。模型假设、完整公式、局限及结果分析以根目录 README 为准。
